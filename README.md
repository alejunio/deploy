## PixelRaid Landing

Landing page em Next.js com tema de games, pronta para rodar localmente ou em
Docker.

## Rodar localmente

```bash
npm run dev
```

Abra:

```text
http://localhost:3000
```

## Rodar com Docker

```bash
docker compose up -d --build
```

Abra:

```text
http://localhost:3000
```

## Arquivos de producao

- `Dockerfile`
- `docker-compose.yml`
- `.dockerignore`

## Validacao

```bash
npm run lint
npm run build
```
